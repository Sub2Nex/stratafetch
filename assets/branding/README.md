# StrataFetch universal icon

Generated with the built-in imagegen tool on 2026-10-16. The committed master is `stratafetch-master.png`. Native EXEs, NSIS setup/uninstall, desktop windows, macOS icon generation, bundled SVG raster wrapper, extensions and GitHub artwork derive from this same image. The SVG is a raster wrapper, not vector source.

Run `python scripts/export-branding.py` with Pillow to reproduce the production exports. Chrome's 128px listing icon has 96px artwork and 16px transparent margins. Smaller toolbar icons fill their canvas for readability. The ICO contains 16/24/32/48/64/128/256px images. Native windows decode the 512px export once and resize for DPI.

Upload `github-social-preview.png` in repository Settings > General > Social preview; upload `icon-512.png` as an account/avatar image only if desired. Repository artwork does not automatically change the GitHub account avatar.
