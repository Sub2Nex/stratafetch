# Roadmap

## Release blockers

1. Full desktop interaction verification, explicit Windows pipe ACLs, and symlink/reparse-point race hardening.
2. Crash recovery across finalization/database boundaries and large fault-injection suite.
3. Independent Windows/Linux/macOS CI results, dependency audit/license review, browser end-to-end validation.

## Next milestones

1. Queue settings, scheduling, categories, global bandwidth policy, retry diagnostics, and instant bandwidth changes.
2. Multi-selection, drag/drop, full Swedish localization, accessible keyboard navigation, notifications and tray.
3. Native browser registration installer, reliable errors for context-menu handoff, explicit authenticated requests.
4. Adaptive segmentation, Retry-After date parsing, measured benchmarks and slow-disk optimization.
5. Signed Windows installer, verified Linux packages and macOS app bundle/signing.

Future protocol adapters and authorized unencrypted HLS/DASH require separately validated parsers, segment assembly, and muxing. DRM bypass is outside scope.
